<!-- ======================================================================
     MAKING IT BULLETPROOF — one-time, ~5 minute setup
     Everything above marked ⚠️ depends on a small GitHub Action running
     INSIDE your own repo instead of a shared public server, which is why
     they're the reliable ones. Repo must be named exactly
     "chandraprakashmishra18" (GitHub's convention for a profile README).

     1. In this repo, create the folder: .github/workflows/
     2. Drop in the two files provided alongside this README:
          - snake.yml      -> generates the contribution snake every 6 hrs
          - metrics.yml    -> generates the full animated metrics dashboard
     3. Also add banner.svg (provided) to the ROOT of this repo — that's
        what makes the terminal-typing banner at the top load instantly,
        with zero dependency on any external server ever going down.
     4. For metrics.yml only: go to
          https://github.com/settings/tokens/new
        Create a classic Personal Access Token with scopes: repo, read:user
        Then in THIS repo go to Settings -> Secrets and variables -> Actions
        -> New repository secret -> name it METRICS_TOKEN -> paste the token.
     5. Commit and push. Go to the "Actions" tab of this repo and run both
        workflows once manually (workflow_dispatch) instead of waiting
        for the schedule.
     6. Refresh your GitHub profile.

     If the stats/streak cards near the top ever show broken images again,
     that's the shared vercel/demolab servers being overloaded, not your
     file. The permanent fix is self-hosting your own copy:
       https://github.com/anuraghazra/github-readme-stats#deploy-on-your-own-vercel-instance
     (one click "Deploy to Vercel" button on that page, then swap the
     domain in the two stats image URLs above to your own deployment URL).
